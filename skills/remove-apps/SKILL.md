# Skill: remove-apps — fast app-removal workflow

Removes applications from WinUtil's install catalog: entries in `config/applications.json` plus their icons in `config/icons/`. Source-only changes; never edit the generated `winutil.ps1`.

## Prerequisites
- Read `AGENTS.md` first (process / non-negotiables). It references this file (§0.1) and `context/remove-apps.md`.
- Never edit `winutil.ps1` directly (generated build output). Never commit it.
- Never touch `docs/src/content/docs/code-reference/tweaks/` or `/features/` (auto-generated).
- PowerShell (`pwsh`) is available on this host for JSON validation and icon deletion.

## Steps

1. **Identify keys.** For each app by `content` name, find its JSON object key in `config/applications.json` and note the matching `.png` icon filename (case-sensitive, e.g. `Lua.png`, `Ruby.png`):
   - `search_codebase -queries ["\"content\": \"App Name\""]` against `config/applications.json`
   - or browse `config/icons/` for the icon filename.

2. **Read each entry block.** Read `config/applications.json` around the key to capture exact `old_text` from the `"key": {` line through its closing `},`. Each entry is unique and non-overlapping.

3. **Remove entries.** Use the editor tool with `old_text` = the full entry block (trailing `},` included) and `new_text` = empty string. All 20+ edits can be batched in one call since blocks don't overlap.

4. **Delete icons.**
   ```
   Remove-Item -LiteralPath 'config/icons/<key>.png'
   ```
   Run for all icons in one command. Watch case (`Lua.png`, `Ruby.png`).

5. **Validate JSON.**
   ```
   pwsh -NoProfile -Command "(Get-Content 'config/applications.json') | ConvertFrom-Json"
   ```
   Confirm it parses with no errors.

6. **Verify removals are gone.** `search_codebase` for each removed key against `config/applications.json` — hits should appear only in the generated `winutil.ps1` (not the source JSON), if at all.

7. **Check git.** `git status --short` should show only `M config/applications.json` and `D config/icons/*.png`. No unrelated files.

## Caveats
- `winutil.ps1` is regenerated by `.\Compile.ps1` / GitHub Actions. Source changes take effect at compile time.
- Pester, Script Analyzer, and `Compile.ps1` availability varies by host — confirm before relying on them.
- Icon filenames are case-sensitive.
- Keep diffs surgical: remove only the requested entries and their matching icons; no drive-by refactors.
