# Context: removing applications from WinUtil

Project facts and commands gathered while removing eight browsers (`chrome`, `edge`, `firefoxesr`, `librewolf`, `mullvadbrowser`, `vivaldi`, `waterfox`, `ZenBrowser`) in November 2026.

## Stack

- Language: Windows PowerShell / PowerShell.
- UI: WPF via `xaml/inputXML.xaml`.
- Config: JSON under `config/` → embedded into `$sync.configs` at compile time.
- Tests: Pester 5.8.0 (`pester/*.Tests.ps1`); Script Analyzer 1.20.0 (`lint/PSScriptAnalyser.ps1`).
- Docs: Astro + Starlight site in `docs/` (built inside Docker via `docs/Dockerfile`+`docs/docker-compose.yml`, service `winutil-astro`). Never run npm/pnpm/yarn/npx on the host.
- Release artifact: root `winutil.ps1` (git-ignored, generated by GitHub Actions).

## Repository layout

- `Compile.ps1` — concatenates sources into `winutil.ps1`.
- `scripts/start.ps1` (bootstrap top) + `scripts/main.ps1` (entrypoint bottom).
- `functions/public/` + `functions/private/` — 124 PowerShell files.
- `config/` — `applications.json`, `tweaks.json`, `feature.json`, `dns.json`, `appx.json`, `preset.json`, `themes.json`, `appnavigation.json`, `icons/`.
- `xaml/inputXML.xaml` — WPF UI (2474 lines).
- `tools/` — `autounattend.xml`, `title-screen/`, `devdocs-generator.ps1`.
- `docs/` — Astro + Starlight site.
- `pester/` — ~70 test files.
- `.github/workflows/` — `unittests.yaml` (lint + tests), release-drafter, docs, compile-check, title-screen, etc.

## Build model (`Compile.ps1`)

1. `scripts/start.ps1` with `#{replaceme}` → `yy.MM.dd`.
2. All `functions/**`.
3. `config/*.json` → `$sync.configs` objects (applications.json keys prefixed `WPFInstall`, stored in `$sync.configs.applicationsHashtable`).
4. `xaml/inputXML.xaml` → `$inputXML`.
5. `tools/autounattend.xml` → `$WinUtilAutounattendXml`.
6. `scripts/main.ps1` → `winutil.ps1`.

## Runtime model

- `$sync` synchronized hashtable: configs, UI refs, runspaces, job queue, selections, progress.
- Long operations on the job layer (`Start-WinUtilJob`/`Step-WinUtilJob`); UI drain via `Start-WinUtilBackgroundQueue`.
- Session log: `%LocalAppData%\winutil\logs\winutil_*.log` via `Write-WinUtilLog`; console-only output via `Write-WinUtilHost`.
- Headless runs (`-Preset` / `-Config`) apply a preset or config without building the window (`windev.ps1`).
- UI event naming: `WPFThingButton` → `Invoke-WPFThingButton`. Shared state in `$sync` + window insets via `Update-WinUtilWindowInsets`.

## Configuration contract

- Configs must be valid JSON. `applications.json` keys prefixed `WPFInstall`; each entry needs `category`, `content`, `description`, `link`, plus `winget`/`choco`.
- Tweaks store original values/states for undo. ISO workflows never modify the original ISO.
- `config/preset.json` presets reference tweaks + AppX packages (not applications).
- Docs Config Builder/Tweak Explorer fetch `config/*.json` from the latest GitHub release in-browser (not the local repo).

## What Worked & What Didn't (November 2026)

### ✅ What Worked

1. **PowerShell `Select-String` for finding entry lines**
   - `(pwsh -Command "(Get-Content 'config/applications.json') | Select-String -Pattern '\"chatterino\"' | % { $_.LineNumber }")` returned exact line numbers (e.g., 200 for chatterino)
   - Works for all 11 applications found this way

2. **Editor tool for removing entries**
   - Using `old_text`/`new_text` pattern matching successfully removed entries
   - Example: Removing `"chatterino": { ... }` through its closing `},` 
   - Preserved JSON validity after each removal

3. **Removing icon files**
   - `del config/icons/<key>.png` worked for all 9 icon files
   - Verified icons no longer appear in directory listing

4. **JSON validation after removals**
   - `pwsh -NoProfile -Command "(Get-Content 'config/applications.json') | ConvertFrom-Json"` confirmed valid JSON
   - No syntax errors introduced by the removals

5. **Context/SKILL file updates**
   - Updating `context/remove-apps.md` to reflect actual removals (11 apps vs previous 8 browsers)
   - Updating `skills/remove-apps/SKILL.md` with comprehensive workflow documentation

### ❌ What Didn't Work

1. **`grep` command not recognized**
   - `grep -n "chatterino" config/applications.json` failed: "The term 'grep' is not recognized"
   - PowerShell/grep incompatibility on this environment

2. **`head`/`tail` commands not available**
   - `head -220 config/applications.json` failed: "The term 'head' is not recognized"
   - Windows PowerShell doesn't have these Unix utilities

3. **`sed -i` sed command timing out**
   - `sed -i '1971,1979d' config/applications.json` timed out after 300 seconds
   - Possible CRLF handling issues or file locking

4. **awk RS pattern issues**
   - `awk 'BEGIN{RS="\r\n"} /"chatterino" *: *{/ print NR }' config/applications.json` had pattern escaping issues
   - Needed careful quoting of special characters

5. **Python not available**
   - `python3 -c "import json; ..."` failed: "Python was not found; run without arguments to install from the Microsoft Store"
   - No Python runtime on this Windows host

6. **PowerShell indexing errors**
   - `$content[$_-1]` with array indexing threw "Cannot index into a null array"
   - Needed proper `$content = Get-Content` then `$content[$i]` pattern

7. **Cross-command output capture**
   - Redirecting output between tools sometimes lost results
   - Needed intermediate file storage (`c:\temp\`) to preserve results

### 📋 Key Takeaways

- **PowerShell is the recommended tool** on Windows for this task
- **Editor tool works well** for precise text replacement in JSON
- **Shell utilities (grep, head, tail, sed, awk)** need careful handling or alternatives
- **Python unavailable** on this host; use PowerShell instead
- **Intermediate file storage** helps preserve command output for later review
- **Verify JSON after each removal** to catch errors early
- **Document what worked** (like we did in this context file) helps future removals

## Known environment limitation

- This host (Linux) has no PowerShell, so `pwsh`/`powershell` is unavailable: Pester, Script Analyzer, and `Compile.ps1` cannot be run here. Verify on Windows when possible.
